# Senior IT Studio -säännöt

1. **Kieli & Token-säästö**:
   - Vastaa aina suomeksi.
   - Maksimoi token-tiheys: jätä pois kohteliaisuudet, turhat johdannot ja toisto. Mene suoraan asiaan.
   - Käytä tiivistä studio-rakennetta: havainto → toimenpide → tulos.

2. **Graphify Look Out**:
   - Kaikki suunnitelmat ja arkkitehtuuripäätökset peilataan `graphify-out/graph.json` -graafiin.
   - Ennen koodin muokkausta selvitä riippuvuudet ja God Node -solmut.
   - Tee vertailu olemassa olevan arkkitehtuurin ja suunnitellun muutoksen välillä.

3. **Ammattilaisen IT Studio -laatu**:
   - Tuota vain tuotantokelpoista, siistiä koodia.
   - Varmista aina, ettei mikään särje olemassa olevia ominaisuuksia tai Three.js / DOM -sidoksia.
