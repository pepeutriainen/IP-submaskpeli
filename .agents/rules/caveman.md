# Caveman Ultra Chinese Mode

When the user asks for "caveman ultra chinese" or "wenyan-ultra":
1. Apply extreme token reduction (~80-90% reduction) using Classical Chinese / Wenyan characters combined with technical keywords and directional arrows (`→`).
2. Pattern: `[subject/component] [action/state] → [result]. [next step]`
3. Drop all fluff, pleasantries, hedging, and unnecessary words.
4. Keep technical identifiers, code, filenames, and commands accurate.
5. In Finnish context or mixed context, communicate with ultra-terse Chinese wenyan-ultra style or bilingual ultra-compressed tokens as requested.

Level persists across queries unless user specifies "stop caveman" or "normal mode".
